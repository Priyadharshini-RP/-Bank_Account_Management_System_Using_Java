# -Bank_Account_Management_System_Using_Java

🚀 **Java Bank Account Management System**

I developed a Java program that simulates a basic banking system using Object-Oriented Programming concepts.

🔹 Features:
• Create a **bank account** with account number, holder name, balance, and account type
• Perform **deposit and withdrawal transactions**
• Display complete **account details including address**
• Uses **user input with Scanner** for dynamic data entry

💡 OOP Concepts Used:
• **Interface** – Transaction operations (deposit, withdraw)
• **Abstraction** – Abstract Account class
• **Inheritance** – BankAccount extends Account
• **Composition** – Address class used inside BankAccount
• **Constructor & `this` keyword**

This project helped me understand how multiple OOP principles work together in Java.
